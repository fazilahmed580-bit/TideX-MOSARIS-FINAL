# TideX P3: AIS & Vessel Analysis Module

## Purpose
The **P3 module** is responsible for evaluating Automatic Identification System (AIS) vessel tracking data to identify candidate vessels that could be responsible for a detected oil spill. P3 ranks these vessels based on spatial proximity, temporal overlap, speed/heading kinematics, and trajectory consistency with the spill's Area of Interest (AOI).

P3 does NOT perform satellite oil-spill detection (P1/P2) or final legal attribution (P4).

## Data Flow (P1 → P3 → P4)
1. **P1 (Detection)** generates a real spill AOI (`spill_aoi.geojson`) and associated observation context (`metadata.json`).
2. **P3 (This Module)** ingests the AOI, observation metadata, and AIS data to reconstruct vessel trajectories and filter for candidates.
3. **P4 (Attribution)** consumes the ranked candidates and features generated by P3 (`candidate_features.json` & `candidates.geojson`) for final evidence analysis.

## Real P1 Input vs. Synthetic Data
- **Real P1 Input:** The production configuration uses `data/spill_aoi.geojson` containing the actual oil spill polygon(s), and `data/metadata.json` which provides the context of the observation. The real P1 event occurred in the Gulf of Mexico.
- **Synthetic AIS Regression Dataset:** The file `data/synthetic_ais.csv` is a synthetic dataset originally created for a hypothetical event near Taiwan. It is preserved strictly for **regression testing** to ensure the core logic of the pipeline continues to work. When running the pipeline with the P1 AOI and the Taiwan synthetic AIS data, 0 meaningful (spatially compatible) candidates will be found, which is expected.

## Running the Pipeline
You can run the pipeline with the default configuration (P1 AOI and synthetic AIS):
```bash
python run_pipeline.py
```

### Configurable Arguments
The pipeline accepts the following command-line arguments to override inputs:
- `--aoi`: Path to the spatial AOI (GeoJSON). Defaults to `data/spill_aoi.geojson`.
- `--ais`: Path to the AIS data CSV. Defaults to `data/synthetic_ais.csv`.
- `--time-start` / `--time-end`: ISO formatted strings defining the analysis time window (e.g., `2021-10-09T11:00:00Z`).

**Time-Window Requirement:** `metadata.json` does not provide an AIS analysis time window. If you provide a custom `--ais` dataset, you MUST provide `--time-start` and `--time-end` arguments. If using the default synthetic dataset, the pipeline falls back to the known synthetic regression time window.

## Generated Outputs
The pipeline outputs to the `outputs/` directory:

### 1. `candidates.geojson`
A standard GeoJSON FeatureCollection containing the reconstructed trajectory LineStrings for each evaluated vessel. This allows visual mapping of the vessel tracks against the AOI.

### 2. `candidate_features.json`
A JSON array of candidate objects containing explainable ranking metrics and features, including:
- `mmsi` & `vessel_name`
- `candidate_score`: Overall relevance score (0-100)
- `distance_km`: Closest spatial distance to the AOI
- `time_difference_minutes`: Temporal proximity to the analysis window
- Kinematics (`mean_speed_knots`, `mean_heading_deg`)
- `evidence`: Human-readable list of factors contributing to the score, essential for P4.
